# Выборы — Godot 4 (для телефона)

Симулятор выборов с Liquid Glass меню. Портрет, 540×1170, рендер `gl_compatibility` (работает почти на любом Android).

## Как открыть и собрать
1. Godot **4.3+** (подойдёт и редактор Godot для Android) → Импорт → `project.godot`.
2. Проект → Экспорт → пресет **Android** уже настроен (`com.verity.elections`, arm64). Нужны шаблоны экспорта и ключ debug.
3. Либо GitHub Actions: `.github/workflows/build-apk.yml` (запуск вручную, не проверялось).

## Что внутри
- **Меню** (Liquid Glass): «Один» — ваш голос против виртуальных избирателей; «Локально» — телефон по кругу, голос тайный.
- **Партии**: добавить, изменить, «Снять» с выборов / «Вернуть», удалить; фото партии (из галереи или встроенный значок); баннер.
- **Проценты**: слайдер у каждой партии, «До 100%», «Поровну». Результат считается от суммы процентов активных партий.
- **Редактор баннеров** (как в CapCut): фон (градиент / цвет / 10 встроенных), текст, фигуры, стикеры, слои; двигать пальцем, размер, поворот, прозрачность, цвет, порядок, дубль, удаление; экспорт в PNG.
- **Встроенные баннеры**: `assets/banners/b01..b10.svg`.
- **Своя клавиатура** с языками: РУС, ENG, FRA, ITA, ՀԱՅ + обои клавиатуры.
- **Настройки**: оформление (редактировать интерфейс, клавиатура-обои, тема), «конус» → «Деп процентов», страны: Россия, США, Франция, Италия, Армения.
- **Итоги**: проценты, голоса, места по барьеру, полукруг парламента.

## Как понимается «конус / Деп процентов»
«Деп процентов» = барьер в % голосов, который партия должна набрать, чтобы получить депутатские места. Места делятся пропорционально (метод наибольших остатков) по числу мест палаты: Россия 450, США 435, Франция 577, Италия 400, Армения 105. Если вы имели в виду другое — скажите, поменяю.

## Партии (настоящие названия)
Названия — реальные партии пяти стран. Проценты — доля голосов на последних выборах, пересчитанная на 100% между перечисленными партиями (малые партии не включены):
- Россия: Госдума, сентябрь 2026 (по партийным спискам, 98,9% обработано). «Яблоко» не было допущено к списку — оно добавлено как «снятая» партия (0%): верните кнопкой «Вернуть».
- США: Палата представителей, 2024 (округлённо; малые партии приблизительно). Итоги 2026 на момент сборки ещё подсчитывались.
- Франция: выборы в Европарламент, 2024 (доли по партиям; на Национальное собрание голосуют по округам).
- Италия: Палата депутатов, 2022.
- Армения: июнь 2026 (все четыре силы из итогов ЦИК; 105 мест с учётом мест нацменьшинств).
Цвета и значки подобраны мной, а не официальные. Любую партию можно изменить, удалить или добавить свою.

## Настоящие логотипы
Официальные логотипы защищены авторским правом и товарными знаками — в проект я их не клал. Два способа:
1. Положить файлы в `assets/party_logos/` с именами из `assets/party_logos/README.txt` (например `ru_kprf.png`) — приложение подхватит само.
2. В приложении: Партии → Изменить → «Фото из галереи».

## Сохранение
`user://elections_save.json` (настройки и партии). Фото партий — `user://logos/`.

## Фото из галереи
Используется системный диалог (`use_native_dialog`). Если на вашей версии Godot он недоступен, откроется обычный FileDialog (нужно разрешение на фото). Если фото не открылось — выберите встроенный значок.

## Файлы
- `scripts/app.gd` — данные, настройки, подсчёт мест, сохранение (автозагрузка `App`)
- `scripts/main.gd` — навигация, фон, клавиатура, уведомления
- `scripts/glass.gd`, `gbutton.gd`, `shaders/glass.gdshader` — Liquid Glass
- `scripts/keyboard.gd` — клавиатура; `banner_view.gd` — отрисовка баннеров
- `scripts/screens/*` — экраны
